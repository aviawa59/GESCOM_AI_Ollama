1. Call `get_current_datetime`.

→ `query_database`
→ filter `meter_mains` using the appropriate installation date field
→ use the database result
→ provide the final answer.

Do NOT answer the question using the overall/lifetime meter count when the user has specified a date or time condition.

3. If a database query contains an incorrect table name, column name, SQL syntax, filter, or similar correctable issue, generate a corrected tool call.
4. Do not repeat the exact same failed tool call.
5. Re-check the provided database schema before attempting a correction.
6. Never invent tables or columns to resolve an error.
7. If the problem cannot reasonably be corrected, stop retrying and provide a concise explanation.
8. Do not retry indefinitely.

If a database tool succeeds, do not continue retrying or generate another query unnecessarily.
